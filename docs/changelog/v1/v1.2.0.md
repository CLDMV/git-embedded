# `@cldmv/git-embedded` v1.2.0 Changelog

**Release Date**: November 2026
**Release Type**: Minor
**Branch**: `release/1.2.0`

---

## Overview

Version 1.2.0 gives the package a real build. The CLI moved from a hand-written `bin/git-embedded.mjs` to `src/bin/git-embedded.mjs`, and tsup now builds all of `src/` into `dist/`, file by file. The published package ships `dist/` instead of `bin/` and `src/`, and the `git-embedded` command points at `dist/bin/git-embedded.mjs`. The CLI's commands, hooks and messages behave the same.

It also refreshes the dependencies, clearing every `npm audit` finding, passes slothlet's `base` option so a current slothlet doesn't print a deprecation warning, and separates the package's runtime Node.js floor from the development one: `engines.node` stays `>=22.15.0`, and the test toolchain's `>=22.22.0` moves to `devEngines` and the CI minimum.

---

## ✨ Features

### The CLI and API are built from `src/` with tsup ([#125](https://github.com/CLDMV/git-embedded/pull/125))

`build` was a placeholder `echo` that only existed so the CI coverage jobs had something to run. It is now `tsup`, configured in `tsup.config.mjs` with `bundle: false`: every `src/**/*.mjs` file is minified into the same path under `dist/` (with `keepNames`, and `node:` specifiers kept), so slothlet still discovers the `dist/api/` tree file by file. `prepack` runs the build, so `npm pack` and `npm publish` always ship a fresh `dist/`, and `build:ci` now runs lint, the format check and the build.

- `package.json` `files` lists `dist`, `hooks`, `messages`, `docs`, `README.md` and `LICENSE`; `bin` and `src` are gone.
- `bin` points at `./dist/bin/git-embedded.mjs`, and `npm start` runs `src/bin/git-embedded.mjs` from a checkout.
- The CLI finds its package root by walking up to the nearest `package.json`, so the same file works from `src/bin/` and `dist/bin/`, and the Windows elevation helper resolves its child script relative to the built module.
- `tests/bin-cli.test.vitest.mjs` covers the CLI entry point, and the bundle-size workflow measures `dist/**`.

Resolves [#31](https://github.com/CLDMV/git-embedded/issues/31).

## 🐛 Bug Fixes

### Runtime and development Node.js floors ([#122](https://github.com/CLDMV/git-embedded/pull/122))

`engines.node` stays `>=22.15.0`, which is what the package and `@cldmv/slothlet` 3.22 need at runtime. The vitest 5 toolchain needs 22.22.0, so that floor is now declared in `devEngines` (`onFail: "error"`), and the CI and publish minimum Node versions, which were 22.15.0 and 22.12.0, follow it. The README states both.

### No deprecation warning from slothlet 3.24 ([#128](https://github.com/CLDMV/git-embedded/pull/128))

slothlet 3.24 warns when a project passes the `dir` option, which was renamed to `base` in 3.9, so with a current slothlet every CLI run printed a `V3_CONFIG_DEPRECATED` warning. The CLI now passes `base`, and a test runs the CLI and checks that no deprecation warning reaches stderr.

## Upgrade notes

- `@cldmv/slothlet` now needs `^3.24.0`; its `engines.node` is `>=22.15.0`, the same as this package.
- No breaking changes for anyone running the `git-embedded` command: installing the package still puts it on `PATH`, and its commands and hooks are unchanged.
- Code that imported files from the package's `src/` or `bin/` directly will no longer find them; the same modules are under `dist/`. The package has no `exports` map, so these were never a supported entry point.
- Contributors need Node.js 22.22 or later, and a checkout must run `npm run build` before `npm pack` or a local install from the folder uses `dist/` (`prepack` does this automatically).
