# @cldmv/git-embedded v1.1.4 Changelog

**Release Date**: August 2026
**Release Type**: Patch

---

## Overview

A test-tooling release: every vitest test file is renamed from `*.test.mjs` to the CLDMV-standard `*.test.vitest.mjs`, and the configs that discover them are updated to match. No runtime code changed ([#39](https://github.com/CLDMV/git-embedded/pull/39)).

---

## 🔧 CI & tooling

- All 17 test files under `tests/` are renamed (for example `tests/helpers.test.mjs` → `tests/helpers.test.vitest.mjs`), keeping history via rename.
- `.configs/vitest.config.mjs` `include` and `tests/run-vitest.mjs` `testFilePattern` now match `*.test.vitest.mjs`, and the test-globals block in `.configs/eslint.config.mjs` uses the same glob. A handful of the renamed tests also had one to six lines edited to follow the new file names.

---

## Upgrade notes

- No runtime changes. The `tests/` folder is not part of the published package.
